# Commit, push, and verify remote delivery

This records Apocky's explicit September 5, 2026 instruction to commit and push owned work and verify its presence on the intended remote before declaring delivery complete.

`COMPLETION_CONTRACT.csl` is the shared contract. `scope-manifest.json` lists the exact live instruction and goal surfaces, their before/after fingerprints, and the portable deltas in `deltas/`. The deltas contain only this amendment. Private goal bodies, database records, unrelated changes, and original preimages are kept locally.

Text patches use zero context to avoid copying unrelated material. JSON merge patches add only the `version_control` contract and preserve all prior keys and values. Verify the named preimage before applying a delta. Existing operational and ethical protections remain in force; the Prime Directive amendment changes its version label and adds section 12 while preserving its earlier protection text.

This policy keeps capability acceptance separate from delivery. It preserves goal objectives, statuses and budgets, and does not resume inactive tasks. The integration owner commits and pushes the governed change, then independently verifies the remote reference and tree. Missing remote access or a rejected push remains a reported delivery blocker.

The version-control gate applies to goals and tasks with authorized owned file changes. Read-only work and no-change results still require outcome evidence, but do not require empty commits or a remote write.
